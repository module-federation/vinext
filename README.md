# @module-federation/vinext

Module Federation integration for vinext.

## Install

```sh
pnpm add @module-federation/vinext
```

## Development

```sh
pnpm install
pnpm run check
```

## Release

Releases are published from GitHub Actions with npm trusted publishing. See
[docs/releasing.md](docs/releasing.md) for the one-time setup and release
process.
